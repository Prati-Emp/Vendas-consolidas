# Acompanhamento e Indicadores RH

Mini-app standalone baseado na estrutura do `streamlit_administrativo`, mas com **somente duas páginas**:

- `Indicadores Gestão de Pessoas`
- `Acompanhamento RH`

## Deploy no Streamlit Cloud

| Campo | Valor |
|-------|--------|
| **Repository** | `Prati-Emp/Vendas-consolidas` |
| **Branch** | `main` |
| **Main file path** | `streamlit_Acompanhemento_indicadores_RH/app.py` |

## Executar localmente

```bash
streamlit run streamlit_Acompanhemento_indicadores_RH/app.py
```
