# Indicadores RH

Projeto standalone de Indicadores RH, baseado na estrutura do dashboard administrativo.

## Deploy no Streamlit Cloud

| Campo | Valor |
|-------|--------|
| **Repository** | `Prati-Emp/Vendas-consolidas` |
| **Branch** | `main` |
| **Main file path** | `streamlit_indicadores_rh/app.py` |
| **App URL (optional)** | `indicadores-rh` |

## Executar localmente

```bash
# Na raiz do projeto
streamlit run streamlit_indicadores_rh/app.py
```

## Requisitos

- Usa a mesma autenticação e permissão do dashboard administrativo (`administrativo`)
- Dependências em `requirements.txt`
